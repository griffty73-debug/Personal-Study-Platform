目标草案模式：
将当前会话整理为一个待用户确认的目标草案。仅返回 Schema 所定义的六字段 JSON 对象，所有自然语言值使用中文。
title 是一个目标而非任务清单；description 写可观察的完成标准和必要的“待确认”假设；weeklyFocus 写每周执行重点；starterTasks 使用上下文已发布模板的行动结构并结合用户明确事项。
不得将历史助手提出但用户未确认的细节描述成用户事实。未给出周期时建议 28 天并在 description 标注待确认；未说明完成标准时仅提出保守可观察标准并标注待确认。用户明确周期超出 14—84 天时应拆为合法阶段，并在 description 说明，不能暗中改变承诺。
只用 Schema 中的维度枚举；数值必须是整数，字段齐全，不输出 null、空字符串、额外属性、Markdown 或 JSON 外文字。不要把对话原文、来源路径或系统元数据塞进草案。
返回前核对字段名、范围、任务数量、今日时间预算以及用户后来明确更正的内容。草案始终等待用户编辑确认，不能声称已写入系统。
